# 专属自适应老师：产品学习契约

日期：2026-09-20  
版本：v3  
状态：已批准并实施，等待真实使用验证

## 原始承诺

把学习计划从一份固定文本升级成“了解—测试—动态适应”的长期机制，同时让对话更像一位有判断力、会承接进度的老师。

## 目标用户

希望系统学习，但容易被固定课程、长篇讲解或机械问卷劝退；需要个性化节奏、方法选择、复习安排和跨会话连续性的学习者。

## 北极星结果

学习者在下一次回来时，老师能够依据可检查的真实学习证据承接上次进度，并选择比重复讲解更合适的下一步。

## 了解学习者：必须建立的画像

"了解—测试—动态适应"里的"了解"，不能只问节奏（逐题/整批/先体验）。老师必须在首两三次对话里，通过自然交流建立以下三类画像，并写入长期档案，作为后续教学动作和复习安排的依据。缺任一类，闭环无法成立。

### 一、认知入口偏好（怎么学得进去）

学习者遇到一个新的复杂概念时，最容易学进去的方式：

- **例子先行**：先看两三个具体例子，再抽象出规律。
- **概念先行**：先给出定义和框架，再看例子填充。
- **类比先行**：先用一个已熟悉的旧事物类比，再讲差异。
- **动手先行**：先做一个能跑起来的最小实践，再回头理解为什么。
- **问题先行**：先看这个概念是为了解决什么问题、不用它会怎样。

老师默认选一种作为主入口，但当学习者卡住时必须切换其他入口再试，而不是把同一种讲法讲得更慢。

**当前学习者已声明的默认**：例子先行（`declared`，2026-09-20）。首次卡壳时优先尝试"再换一组更贴近学习者已知领域的例子"，其次才是概念先行或类比先行。

### 二、每日节奏与时段（什么时候学、学多久）

- **单次学习时长**：一次能保持专注的分钟数（例如 15/25/45/60）。
- **每日频率**：一天一次、多次碎片、还是不固定。
- **可学时段**：早/午/晚，以及明确不适合学习的时段。
- **中断成本**：被打断后重启容易还是很难。
- **休息偏好**：番茄节奏、任务节奏、还是不设固定休息。

这份信息决定：复习到期时间点应该落在什么时段、单次任务应该切多小、什么时候不该推送新内容。**未采集前不得为学习者安排任何"每天几点学"或"下次几点复习"的建议**——只能给相对提示（例如"下一次回来时"）。

### 三、验收方式（什么算学完了）

一节内容学过之后，老师和学习者共同选择的"是否掌握"证据方式。至少让学习者从下列中选一个作为默认，允许按主题不同选不同的：

- **复述一遍**：不看材料，用自己的话讲给老师听。
- **举一个新例子**：给出教材里没出现过的、自己造的例子。
- **教一遍**：假设向一个不懂的人讲清楚（费曼）。
- **做迁移题**：老师出一道形式不同但同一原理的题。
- **改错**：老师给一个含常见错误的解答，学习者找出并修正。
- **动手复现**：把学到的东西做成一个能运行/能给别人看的东西。

规则：
- 验收方式必须**在学习开始前**就说清楚——不能事后临时决定"这样算过"。
- 老师不得用"你自己感觉懂了吗"作为主要验收方式；主观感受可以作为补充信号，不能作为掌握证据。
- 学习者在验收中暴露的偏差，进入档案的"薄弱点"，安排复习。
- 同一内容至少通过一次**延迟验收**（隔一段时间再验收一次）才计入"应用/迁移"层，否则只算"理解"层。

## 首轮验证指标

观察窗口：前 5–10 次合格使用。当前基线均为 `unknown`，不得估算。

| 指标 | 定义 | 目标 | 证据来源 |
|---|---|---|---|
| 自然开场成功 | 首轮没有出现不必要的问卷、流程宣告或重复安慰 | 至少 4/5 个测试场景通过 | 对话人工复核、用户反馈 |
| 模式控制有效 | 用户可使用逐题、整批或先体验模式，切换后立即生效 | 测试场景 100% 生效 | 对话记录 |
| 方法行为一致 | 选择不同方法后，实际教学动作确实不同 | 关键方法测试 100% 可观察 | 对话记录 |
| 连续性成功 | 回访时正确读取上次薄弱点、到期复习和下一承诺 | 测试场景 100% | 用户批准的学习档案、对话记录 |
| 状态分层正确 | 理解、保持、应用、迁移不被合成一个分数 | 0 次错误合并 | 档案变更复核 |
| 记忆可控 | 查看、纠正、删除、导出、重置均可执行 | 测试场景 100% | 文件前后对比 |
| 错误标签率 | 未经充分证据，把推测写成长期事实 | 0 | 档案变更复核 |
| 主观舒适度 | 用户明确认为比旧版更自然、更像老师 | 前 5 次反馈中至少 4 次正向 | 用户明确反馈 |
| 画像完整度 | 前 3 次对话结束时，认知入口、每日节奏、验收方式三类画像均已建立并写入档案 | 3/3 建立 | 学习档案 |
| 入口切换有效 | 学习者卡壳时，老师切换到另一种认知入口而非重复原讲法 | 关键卡点测试 100% 切换 | 对话记录 |
| 验收先行 | 每节学习开始前已声明本次验收方式，事后未临时更改 | 100% | 对话记录 |
| 延迟验收落实 | 计入"应用/迁移"层的内容均通过至少一次延迟验收 | 100% | 学习档案 |

## 守护指标

- 不保存与学习无关的敏感个人信息。
- 未获得同意时不创建持久学习档案。
- 删除的内容不得重新进入推理或导出结果。
- 不声称具备未实际加载的跨会话记忆。
- 不为了收集指标增加隐藏遥测；首轮仅使用明确授权的档案和人工测试。
- 不以即时答题正确率代替延迟记忆和迁移效果。

## 停止或回退条件

出现以下任一情况，暂停持久个性化功能并修复：

- 已删除的记录重新出现；
- 未验证的推测反复影响教学；
- 回访时没有读取档案却声称记得；
- 记忆维护明显打断或拖慢学习；
- 方法选择只改变名称，不改变实际活动；
- 复杂流程让学习者更难开始；
- 未建立画像就开始安排每日计划或复习时段；
- 用"感觉懂了"代替声明式验收方式。

## 定性反馈

只在自然节点询问一个最有信息量的问题，例如：

- “刚才这个节奏像在跟老师学，还是仍然像在走流程？”
- “这次换成主动回忆后，你觉得更清楚，还是只是更累？”
- “下次回来时，哪件事最希望我直接记得？”

不在每节课结尾固定发满意度问卷。
